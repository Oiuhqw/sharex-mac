ShareX for macOS 0.1.4, build 5

Requires macOS 14 or later on Apple Silicon. The app contains arm64 code only.
Intel Macs are unsupported.

Download ShareX.dmg and ShareX.dmg.sha256 from the same release:
https://github.com/Oiuhqw/sharex-mac/releases/tag/v0.1.4

In the download folder, verify the DMG before installing:

    shasum -a 256 -c ShareX.dmg.sha256

Open the DMG. Drag ShareX.app to Applications, then open it.
ShareX appears in the menu bar. Open the camera icon and choose Region.
Allow Screen Recording in System Settings > Privacy & Security.
Quit and reopen ShareX after you change that permission.

To annotate, choose a drawing, Blur, or Pixelate tool before selecting the area.
Choose Tool > Region or press Tab, then drag the final area.
Release the mouse to copy the finished image. No Done click is needed.
For a plain screenshot, drag the region immediately.
New installations also save a PNG in Pictures/ShareX.
Updates preserve your output settings.

This build is ad-hoc signed with Hardened Runtime. It is not Apple-notarized.
The packaging workflow does not use Developer ID signing.
After the first launch attempt, a downloaded copy may require
System Settings > Privacy & Security > Open Anyway.

If macOS says the verified app is damaged or refuses to open it, remove its
download quarantine flag after copying it to Applications:

    xattr -dr com.apple.quarantine /Applications/ShareX.app

Then open the app again.

If capture permission stops working after an ad-hoc update, remove the old
ShareX entry from Screen Recording permissions. Add the updated
/Applications/ShareX.app, then quit and reopen it.

Changes in 0.1.4:
- Annotate the frozen desktop before selecting the final capture area.
- Region and Freehand selections copy automatically when you release the mouse.
- Region and Tab preserve annotations and commit active text.
- Drawing and tool changes do not copy or save intermediate images.
- Fixed-area and window editors retain Done and crop adjustments.

Changes in 0.1.3:
- Fullscreen editing stays on the original displays.
- Rectangular and freehand selections can cross display boundaries.
- Each display has a fixed top toolbar with Tool, Style, More, Done, and Cancel.
- Style includes blur and pixelation strength. More includes Undo, Redo, and Delete.
- New installations assign only Control-Shift-1 for Region.
- Updates preserve valid saved bindings, including old defaults and disabled shortcuts.
- Last Region supports multiple displays. A changed participating display starts fresh selection.
- The output uses the highest scale of the displays touched by the crop.
- Desktop gaps stay transparent. Oversized output requires a smaller crop.
- App and package builds contain arm64 code only. Intel Macs are unsupported.

Changes in 0.1.2:
- Native Capture, Shortcuts, and Output settings pages have searchable shortcuts.
- Shortcut settings support recording, conflict feedback, clear, restore, and saved assignments.
- Damaged shortcut preferences recover without replacing valid custom assignments.
- New installations copy to the clipboard and save PNG files to Pictures/ShareX.
- Optional crop arrow keys move one image pixel. Shift moves ten pixels.
- Option with an arrow key resizes the crop's trailing edge.
- Later blur and pixelation effects preserve earlier protected pixels.
- Image buffers, cached effects, and live previews have allocation limits.

Included from 0.1.1:
- Clipboard and PNG file export succeed or fail independently.
- Failed outputs show Retry and Save As. The screenshot remains available during recovery.
- Retry preserves successful outputs and does not create duplicate files.
- The success sound plays only after every requested output succeeds.
- The app has an icon and rejects relative save-folder paths.
- The magnifier appears on the first frame and follows the pointer when another app is active.
- Optional editing keys and typed text reach the capture overlay when another app is active.
- Blur and pixelation strength start at 8 points. An opaque filled box covers sensitive content completely.
- Blur uses a reduced-resolution drag preview and full-resolution saved output.

Native automated checks cover capture, editing, clipboard and PNG output,
output recovery, and mixed-scale virtual-display layouts.

Physical mouse transitions, separate Spaces, physical display hot-plug, real
mixed-density display capture, physical shortcuts, and interactive permission
prompts remain hardware checks. See the 0.1.3 assessment in the repository.

Blur and pixelation do not guarantee that sensitive content cannot be inferred.
Use a fully opaque filled rectangle and check the exported image before sharing it.
Other recording apps may capture the editor before redactions are complete.
